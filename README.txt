GamadNg Marketplace starter
1. index.html is a standalone website prototype.
2. Open index.html in a browser for a local preview.
3. Listings are stored only in the same browser/device; no shared server/database or account system is connected.
4. WhatsApp contact opens an external WhatsApp link.
5. This is not yet a production marketplace and does not process payments.
For public launch, upload these files to a suitable HTTPS host and add a shared database/authentication backend.
